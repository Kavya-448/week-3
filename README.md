# Experiment 3: Iterative Prompt Refinement Using Gemini AI

## Aim
To demonstrate how successive prompt improvements can produce clearer and more useful explanations from a language model.

## Problem Statement
To explain photosynthesis to a 10-year-old child by improving a baseline prompt through two refinement stages.

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Google Gen AI SDK

## Prompt Refinement Process

### Iteration 0: Baseline
Explain photosynthesis to a 10-year-old.

### Iteration 1: First Refinement
Add a friendly teacher role, a simple analogy, short sentences, and easy language.

### Iteration 2: Second Refinement
Add a memorable trick and a text-only diagram description.

## Procedure
1. Install the Google Gen AI SDK.
2. Configure the Gemini API key securely.
3. Define a function to send prompts to Gemini AI.
4. Execute the baseline prompt.
5. Execute both refined prompts.
6. Display the responses and analyse the improvements.

## Expected Output
- Three prompt versions and their responses
- Analysis of each refinement
- Final summary of the improvements

## Result
The experiment demonstrates iterative prompt engineering by progressively adding simple language, analogy, memory aids, and visual instructions to improve the usefulness of the generated explanation.
